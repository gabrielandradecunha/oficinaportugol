Lista de Exercícios - Estruturas Condicionais

  1. Leia um número digitado pelo usuário. Se o número for maior que 10, imprima a mensagem: "O número é maior que 10!".
  2. Leia a idade de uma pessoa. Se a idade for maior ou igual a 18, imprima: "Maior de idade". Caso contrário, imprima: "Menor de idade".
  3. Peça ao usuário para digitar uma senha numérica. Se a senha for 1234, imprima: "Acesso permitido". Caso contrário, imprima: "Senha incorreta".
  4. Leia um número inteiro digitado pelo usuário. Verifique se o número é par ou ímpar e imprima a resposta correspondente.
    Dica: use o operador de resto da divisão (%)
  5. Peça ao usuário para digitar a temperatura atual.
    • Se estiver abaixo de 15, imprima: "Está frio"
    • Se estiver entre 15 e 25, imprima: "Clima agradável"
    • Se for maior que 25, imprima: "Está quente"
  6. Leia duas notas de um aluno e calcule sua média.
    • Se a média for maior ou igual a 7.0, imprima: "Aprovado"
    • Se a média estiver entre 5.0 e 6.9, imprima: "Recuperação"
    • Se for menor que 5.0, imprima: "Reprovado"
  7. Leia três números inteiros diferentes digitados pelo usuário. Determine e imprima qual deles é o maior número.
